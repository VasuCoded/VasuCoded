## Vasu

I build things to find out how they work. Web apps mostly, hand-tracking and vision experiments on the side

### Active

- [PaperFlow](https://github.com/VasuCoded/PaperFlow) - Multi-tenant question bank and mistake-practice platform for classes 9 to 12. Tests stay on paper; the app logs right and wrong per question and turns mistakes into targeted practice. Paper generator, multi-set shuffle engine, print-ready keys, row-level security, 275 tests.
- [WhatNow](https://github.com/VasuCoded/WhatNow_Website) - Free, bilingual (English and Hindi) career and exam guidance platform for Indian students. Co-building with a team.
- [Portfolio](https://vasucoded.vercel.app) - My personal site, built with Next.js.

### Dormant

- [Jugaad](https://afterhours.arshnah.in) - Discord economy and community bot with a public docs site that pulls live leaderboards and server activity from the bot's own API.
- [Server bots](https://github.com/VasuCoded/ServerBots) - Smaller custom Discord bots built for specific communities.
- [Project Collab Platform](https://github.com/VasuCoded/Project-Collab-Platform) - One workspace for small teams: chat, task boards, notes, whiteboards, reminders and peer-to-peer voice and video calls, instead of juggling four apps.

### Going public soon

- Veekh - Self-hosted semantic image search. Describe a photo in plain words and find it in your own library, no cloud. CLIP, Qdrant, FastAPI, Docker.
- TouchDesigner builds - Real-time hand-tracking experiments: an invisibility cloak effect, and a gesture-controlled AC circuit visualizer you open by pinching the air.
